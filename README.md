A comprehensive, professional medical clinic website with modern design, booking system, and patient portal.

## Features

### 🏥 Complete Medical Website
- **15+ Professional Pages**: Homepage, Services, Doctors, About, Contact, FAQ, and more
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **SEO Optimized**: Meta tags, semantic HTML, and structured data ready
- **Professional Medical Design**: Clean, trustworthy, and accessible

1. **Homepage** - Hero sections, featured services, doctor highlights

## Deployment

This website can be deployed to:
- **Vercel** (Recommended - instant deployment)
- **Netlify** (Great for forms and functions)
- **GitHub Pages** (Free hosting)
- **Any static hosting service**

### Quick Deploy to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

## Customization

### Update Contact Information
Edit contact details in each page's footer and contact.html

### Add/Remove Services
Modify the services section in services.html

### Update Doctor Profiles
Edit doctor information in doctors.html

### Change Colors
Update CSS variables in css/style.css:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #7c3aed;
    /* etc... */
}
```
